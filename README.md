# SHIBA LOOP（プロトタイプ）

柴犬だけを操作して、何も知らずに散歩を続ける飼い主を事故から救うアクションゲームの
ブラウザ・プロトタイプ。

検証したいのは一点だけ:

> **犬のわがままに見える行動によって、飼い主の未来を間接的に変えることが面白いか。**

完成品ではない。1〜3分でひと通りの体験を確認するためのものだけを入れてある。

## 動かす

```bash
npm install
npm run dev      # http://localhost:5173
```

```bash
npm run build    # 型チェック + 本番ビルド（dist/）
npm run preview  # ビルド結果を確認
```

## 公開

`main` に push すると GitHub Actions が Vite でビルドして GitHub Pages へ出す
（`.github/workflows/pages.yml`）。最初の一度だけ、リポジトリの
**Settings → Pages → Source** を **GitHub Actions** にする必要がある。
プライベートリポジトリの Pages は有料プランの機能なので、無料プランなら
リポジトリを public にする。

`vite.config.ts` の `base` は `'./'`（相対パス）にしてあるので、
`https://<user>.github.io/shiba-loop/` のようなサブパスでもそのまま動く。

## 操作

| キー | 動作 |
| --- | --- |
| `WASD` / 矢印 | 柴犬を動かす（カメラ基準） |
| `Space` | **拒否柴**。踏ん張る。リードが張っていれば飼い主の足が止まる |
| `E` | **抱っこ要求**。飼い主の近くでのみ。飼い主が約1.8秒しゃがむ |
| （キーなし） | **リードで引っ張る**。最大距離まで離れて動き続けると、飼い主が少しずれる |
| `Enter` / クリック | 決定（時間を巻き戻す・タイトルから再開） |

デバッグ:

| キー | 動作 |
| --- | --- |
| `R` | 最初からやり直す |
| `T` | 事故の1.5秒前まで早送り |
| `G` | 事故を即発生させる |
| `H` | 当たり判定・リード範囲・Waypoint の表示 ON/OFF |

## ひと通りの流れ

1. 散歩が始まる。飼い主は勝手に歩く。犬はリードの届く範囲だけ自由
2. 約10秒後、工事現場から看板が飛んでくる。**1周目は基本的に死ぬ**
3. 飼い主が倒れる。犬が近付くと、工事現場の奥に黒い人型の怪異が一瞬だけ見える
4. 首輪のアイテムが光る。`Enter` で**時間を巻き戻す**（事故の約6秒前）
5. 2周目。事故の直前に `E` で抱っこをせがむ。飼い主は「はいはい、抱っこね」としゃがむ
6. 直前まで飼い主を殺した看板が、頭上を通過する
7. 飼い主は何も分かっていない。「今日は甘えん坊だな」
8. 怪異だけが犬を見ている。暗転 → `SHIBA LOOP` → `Prototype Clear`

飼い主は最後まで、自分が死んだことも助けられたことも知らない。

## 回避の手段は1つではない

看板は「発射した瞬間の飼い主の位置と速度」から着弾点を計算して飛ぶ。だから、

- **しゃがませる**（`E`）→ 頭上を通過する。これが主要手段
- **足を止めさせる**（`Space` + リードが張っている状態）→ 予測が外れて前方に着弾する
- **横にずらす**（リードを引っ張る）→ 上2つと組み合わせると効く

のどれでも助かる。数値を変えれば、どれを主要手段にするかも変えられる。

## 数値の置き場所

**調整したい値は `src/config.ts` の `CONFIG` に集めてある。** リードの長さ、犬と飼い主の
速度、しゃがみ時間、事故の発生時刻、巻き戻す秒数、カメラの画角と角度など。

ブラウザのコンソールから触れる:

```js
CONFIG.leashLength = 5     // リードを伸ばす
CONFIG.ownerSpeed = 2.5    // 飼い主を速くする
CONFIG.signSpeed = 5       // 看板を遅くする（＝避けやすくする）
```

毎フレーム参照しているので、リロードなしで反映される（事故の発生時刻 `hazardTriggerTime`
だけは、そのループの開始時に `Hazard` 側へ写されるので `R` を押すまで効かない）。

`game` もグローバルに出してある（`game.state`, `game.loopTime` など）。

## 構成

```
src/
  config.ts               調整可能な数値。処理の中に数字を埋めない
  main.ts                 起動
  Game.ts                 状態遷移・進行・演出のつなぎ
  entities/Dog.ts         柴犬（プリミティブの寄せ集め・姿勢・スナップショット）
  entities/Owner.ts       飼い主（WALKING / STOPPED / CROUCHING / DEAD）
  entities/Wraith.ts      怪異
  systems/Input.ts        キー入力
  systems/Leash.ts        リード（犬の制限・飼い主への引っ張り・描画）
  systems/CameraRig.ts    固定気味の見下ろしカメラ・シェイク
  systems/History.ts      巻き戻し用の記録
  hazards/Hazard.ts       事故の共通インターフェース
  hazards/FlyingSignHazard.ts  飛来する看板
  world/World.ts          街・散歩コース
  ui/UI.ts                DOM側の表示
```

### 事故を足すとき

`Hazard` インターフェースを実装したクラスを1つ作って、`Game` の `hazards` に足すだけ。
`update` / `reset` / `forceTrigger` / `snapshot` / `restore` の5つを埋める。
`snapshot` / `restore` があるので、巻き戻しは自動的に効く。

置き場所だけ用意してある将来の事故: 車（車道と路上駐車）、マンホール（歩道上）、
落下物（工事現場の足場）、自転車。

### タイムリープの実装

状態履歴の作り込みはしていない。毎フレーム、犬・飼い主・事故の姿勢を配列に積んでおき、
巻き戻し時にそれを逆再生する（`systems/History.ts`）。逆再生の見た目と、戻り先の
状態復元を同じ仕組みでまかなっている。画面の歪みは CSS フィルタ（`index.html`）。

## 技術

Vite + TypeScript + Three.js のみ。物理エンジンは入れていない（当たり判定は
「球と線分の距離」だけ）。外部アセットなし、全部 Primitive Geometry。
カメラは OrthographicCamera の固定気味の見下ろし。

## 検証の状態

- `npm run build`（`tsc --noEmit` + `vite build`）は通る
- ヘッドレス Chromium で通しプレイを自動実行し、以下は確認済み:
  1周目に事故で死ぬ／怪異が出る／巻き戻しで2周目に入る／`E` の抱っこで回避して
  クリアまで到達する／`Space` の拒否柴だけでも回避できる／`R` `T` `G` `H` が動く
- **手触り（面白いかどうか）は未確認。** そこは人が実際に触って判断するもの
- 音は入れていない。スマホ対応もしていない

## やっていないこと

モバイル対応、音声、高度なアニメーション、完璧なコード設計。

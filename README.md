# SHIBA LOOP（プロトタイプ）

柴犬だけを操作して、何も知らずに散歩を続ける飼い主を事故から救うアクションゲームの
ブラウザ・プロトタイプ。

検証したいのは一点だけ:

> **犬のわがままに見える行動によって、飼い主の未来を間接的に変えることが面白いか。**

完成品ではない。数分でひと通りの体験を確認するためのものだけを入れてある。

## 動かす

```bash
npm install
npm run dev      # http://localhost:5173
```

```bash
npm run build    # 型チェック + 本番ビルド（dist/）
npm run preview  # ビルド結果を確認
```

## 公開

`main` に push すると GitHub Actions が Vite でビルドして GitHub Pages へ出す
（`.github/workflows/pages.yml`）。

**最初の一度だけ、手で有効にする必要がある。**
リポジトリの **Settings → Pages → Source** を **GitHub Actions** にする。
ワークフローには `enablement: true` を付けてあるが、`GITHUB_TOKEN` には
Pages サイトを新規作成する権限がないため（`Resource not accessible by integration`）、
初回はこれだけ人がやる。以降は push するだけで反映される。

プライベートリポジトリの Pages は有料プランの機能なので、無料プランなら
リポジトリは public にしておく。

## 操作

| 動作 | キーボード | タッチ（iPad など） |
| --- | --- | --- |
| 柴犬を動かす（カメラ基準） | `WASD` / 矢印 | 画面左半分をなぞる（触った場所にスティックが出る） |
| **拒否柴**。踏ん張る。リードが張っていれば飼い主の足が止まる | `Space` | 「拒否柴」ボタンを押しっぱなし |
| **抱っこ要求**。飼い主の近くでのみ。飼い主が約1.8秒しゃがむ | `E` | 「抱っこ」ボタンをタップ |
| **リードで引っ張る**。最大距離まで離れて動き続けると、飼い主が横にずれる | 専用キーなし | 専用ボタンなし |
| **電柱にリードを巻きつける**。電柱の向こうへ回り込むと引っかかり、飼い主が進めなくなる | 専用キーなし | 専用ボタンなし |
| 決定（時間を巻き戻す・スキップ・タイトルから再開） | `Enter` | 画面のボタンをタップ |

デバッグ:

| キー | 動作 |
| --- | --- |
| `R` | 最初からやり直す |
| `T` | 次の事故の少し手前まで早送り |
| `G` | 次の事故を即発生させる |
| `H` | 当たり判定・リード範囲・Waypoint の表示 ON/OFF |

デバッグキーはキーボードのみ。タッチ端末では使えない。

## iPad で遊ぶ

公開URLを Safari で開くだけ。タッチ端末（`(pointer: coarse)` か `maxTouchPoints > 0`）を
検出すると、自動で画面上のスティックとボタンに切り替わり、操作説明の文言もタッチ向けになる。

- **横向き推奨。** 縦持ちでも遊べるが画角が狭い（縦のときは画面上部にその旨を出す）
- **ホーム画面に追加**すると Safari のバーが消えて全画面になる
- ピンチ拡大・ダブルタップ拡大・スクロールは止めてある
- タッチ端末では描画解像度を `devicePixelRatio` の 1.5 倍までに抑えている

PCでタッチUIを確認したいときは URL に `?touch=1` を付ける。

## ひと通りの流れ

1. 散歩が始まる。飼い主は勝手に歩く。犬はリードの届く範囲だけ自由
2. 工事現場から看板が飛んでくる。**1周目は何も知らないので死ぬ**
3. 飼い主が倒れる。犬が近付くと、工事現場の奥に黒い人型の怪異が一瞬だけ見える
4. 首輪のアイテムが光る。`Enter` で**時間を巻き戻す**
5. 巻き戻した直後、アイテムが**未来視**を見せてくる。この先の散歩が早送りで流れ、
   飼い主が死ぬ場所が4つとも見える
6. 2周目以降。見た記憶を頼りに、4つの事故を順番に切り抜ける
7. 家に着く。飼い主は何も分かっていない。「今日は甘えん坊だったな」
8. 怪異だけが犬を見ている。暗転 → `SHIBA LOOP` → `Prototype Clear`

飼い主は最後まで、自分が何度死んだかも、助けられたことも知らない。

## 4つの事故と、その避け方

| 事故 | 何が起きるか | 主な避け方 |
| --- | --- | --- |
| **飛来する看板** | 工事現場から看板が頭の高さで飛んでくる | `E` **抱っこ**でしゃがませる |
| **落下物** | 足場から鉄骨が落ちる。落下地点の影が先に出る | `Space` **拒否柴**で足を止める |
| **マンホール** | 蓋の外れた穴に、飼い主がまっすぐ落ちる | **リードで横へ引っ張る** |
| **飛び出す自転車** | 路地から自転車が歩道を横切る | **電柱にリードを巻きつけて**足を止める |

どれも手段は1つではない。看板は「発射した瞬間の飼い主の位置と速度」から着弾点を
計算して飛ぶので、足を止めさせても外れる。落下物は横にずらしても避けられる。
自転車は拒否柴でも間に合う。
ただし**マンホールだけは、止めても再開すれば結局落ちる**ので、横に引くしかない。
リードを引っ張るための事故として置いてある。

避けた瞬間、かすめた距離が近ければ**時間がスローになる**（`CONFIG.slowMoDuration` /
`slowMoFactor` / `closeCallDistance`）。予告から発生までは1.4〜1.5秒しかないので、
だいたいギリギリになる。

### 事故の起こし方（設計上の要点）

事故は**時刻ではなく、飼い主の x 座標**で始まる。時刻にすると、序盤で拒否柴を
使って飼い主を遅らせただけで、後半の事故が全部飼い主のいない場所で空振りする。

かといって「事故の場所に着いた瞬間に起こす」のもだめで、手前で足を止めたら
何も起きなくなり、先へ進めなくなる。

そこで**予告地点 `triggerX` を越えたら、そこから決まった秒数後に必ず起こす**。
止めれば事故だけが先に起きて、飼い主は後ろにいる。これで拒否柴が
「事故の時間をずらす」手段として成立する。

## 電柱にリードを巻きつける

犬が電柱の向こう側へ回り込むと、リードが電柱に引っかかる。そのあいだリードは
「飼い主 → 電柱 → 犬」の折れ線になり、飼い主は**電柱からリードの長さまでしか
進めない**。ボタンを押さずに足を止められる唯一の手段。

犬が電柱から遠くへ行くほど飼い主の行動半径は短くなる。実装上の注意が3つある:

- 引っかかった直後はリードがほぼ一直線なので、折れ角だけで判定すると次のフレームで
  即外れる。**きちんと回り込んで折れ角が付いた（`poleCommitCos`）ときだけ**、
  角度で外れるようにしてある
- 張っているあいだ飼い主を減速させないと、電柱のまわりを滑って回り込んでしまう
- 犬が飼い主側へ戻ると角度が変わらず**永久に固定される**ので、張りっぱなしが
  `poleHoldMax` 秒を超えたら滑って外れる。詰み防止

## 未来視

別のカットシーンは作っていない。**本物のシミュレーションを5倍速で流しているだけ。**
飼い主だけ死なないようにして、当たった瞬間に一瞬止めて事故の名前を出す。
全部見終わったら、元の時点の状態に丸ごと戻す。

そのおかげで「未来視で見たとおりのことが起きる」のが仕組みとして保証される。
`Enter` / タップでスキップできる。

## 数値の置き場所

**調整したい値は `src/config.ts` の `CONFIG` に集めてある。** リードの長さ、犬と飼い主の
速度、しゃがみ時間、各事故の予告から発生までの秒数、巻き戻す秒数、未来視の速さ、
カメラの画角と角度など。

ブラウザのコンソールから触れる:

```js
CONFIG.leashLength = 5      // リードを伸ばす
CONFIG.ownerSpeed = 2.5     // 飼い主を速くする
CONFIG.signSpeed = 5        // 看板を遅くする（＝避けやすくする）
CONFIG.visionSpeed = 10     // 未来視を早送りする
CONFIG.leashMaxPullPerSecond = 2  // 引っ張りを強くする
CONFIG.fallWarnDelay = 3    // 落下物の予告を長くする（＝やさしくする）
CONFIG.poleHoldMax = 6      // 電柱に巻きついていられる時間を伸ばす
```

毎フレーム参照しているので、リロードなしで反映される（事故の予告地点 `triggerX` だけは
インスタンス生成時に決まるので `R` を押すまで効かない）。

`game` もグローバルに出してある（`game.state`, `game.loopTime`, `game.hazards` など）。

## 構成

```
src/
  config.ts               調整可能な数値。処理の中に数字を埋めない
  main.ts                 起動
  Game.ts                 状態遷移・進行・未来視・演出のつなぎ
  entities/Dog.ts         柴犬（プリミティブの寄せ集め・姿勢・スナップショット）
  entities/Owner.ts       飼い主（WALKING / STOPPED / CROUCHING / DEAD）
  entities/Wraith.ts      怪異
  systems/Input.ts        キー入力とタッチ入力の受け口
  systems/Touch.ts        画面上のスティックとボタン（タッチ端末のみ）
  systems/Leash.ts        リード（犬の制限・飼い主への引っ張り・電柱への巻きつき・描画）
  systems/CameraRig.ts    固定気味の見下ろしカメラ・シェイク
  systems/History.ts      巻き戻し用の記録
  hazards/Hazard.ts       事故の共通インターフェース
  hazards/FlyingSignHazard.ts     飛来する看板
  hazards/FallingObjectHazard.ts  落下物
  hazards/ManholeHazard.ts        マンホール
  hazards/BicycleHazard.ts        飛び出す自転車
  world/World.ts          街・散歩コース・電柱の位置
  ui/UI.ts                DOM側の表示
```

### 事故を足すとき

`Hazard` インターフェースを実装したクラスを1つ作って、`Game` の `hazards` に
x の小さい順で足すだけ。埋めるのは:

- `label` / `advice` / `nearMissLine` — 画面に出す名前、避け方、避けたときの飼い主のセリフ
- `triggerX` / `dangerX` — 予告が始まる x と、実際に事故が起きる x
- `update` / `reset` / `forceTrigger` / `setDebugVisible`
- `snapshot` / `restore` — これがあるので、巻き戻しと未来視は自動的に効く

ヒント表示・未来視・スロー演出・デバッグキーは、この5つ+3つから勝手に組み立てる。

まだ置き場所だけ用意してある将来の事故: 車（車道と路上駐車がすでにある）。

### タイムリープの実装

状態履歴の作り込みはしていない。毎フレーム、犬・飼い主・事故の姿勢を配列に積んでおき、
巻き戻し時にそれを逆再生する（`systems/History.ts`）。逆再生の見た目と、戻り先の
状態復元を同じ仕組みでまかなっている。画面の歪みは CSS フィルタ（`index.html`）。

## 技術

Vite + TypeScript + Three.js のみ。物理エンジンは入れていない（当たり判定は
球と線分の距離、円と点の距離だけ）。外部アセットなし、全部 Primitive Geometry。
カメラは OrthographicCamera の固定気味の見下ろし。

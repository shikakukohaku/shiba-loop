# SHIBA LOOP（2Dアクション・プロトタイプ）

柴犬だけを操作する2D横スクロールアクション。飼い主は勝手に歩き、何も気づかない。
犬と飼い主は**リードでつながっている**。それが制約であり、移動手段であり、武器でもある。

検証したいのは一点だけ:

> **飼い主とリードで繋がっていることを活かしたアクションが面白いか。**

完成品ではない。数分で手触りを確かめるためのものだけを入れてある。

## 動かす

```bash
npm install
npm run dev      # http://localhost:5173
```

```bash
npm run build    # 型チェック + 本番ビルド（dist/）
npm run preview  # ビルド結果を確認
```

## 操作

| 動作 | キーボード | タッチ（iPad など） |
| --- | --- | --- |
| 走る | `←` `→` / `A` `D` | 画面左半分をなぞる |
| ジャンプ（長押しで高く、空中でもう1回） | `Space` / `W` / `↑` | 「ジャンプ」 |
| **かみつき**（前へ踏み込んで噛む） | `J` / `Z` | 「かみつき」 |
| **ダッシュ**（短距離を一気に抜ける） | `K` / `Shift` | 「ダッシュ」 |
| やり直す / デバッグ表示 | `R` / `H` | — |

犬の身体能力は高い。走る・跳ぶ・ダッシュで、怪異のまわりを引っかき回せる。

## リードでできること

リードには最大長がある（`CONFIG.leashLength`）。これが全部の土台。

### 1. 振り子と、反動ジャンプ

犬が空中でリードを張ると**振り子**になる。外向きの速度だけを消して接線を残しているので、
飼い主を支点にして勢いよく振れる。

**張っているあいだにジャンプすると、その勢いを足してリードから飛び出す。**
リードは0.36秒だけ緩んでから、また受け止める（`leashReleaseTime`）。
飼い主が歩いているぶん支点も動くので、ぶら下がっているだけでも運んでもらえる。

### 2. リードで締め上げる

`brute`（大きい怪異）は**かみつきが効かない**。弾かれる。

倒すには、**飛び越えて相手の向こう側へ回り込み、リードを相手の体に何度も横切らせる**。
4回横切ると輪が締まって沈む（`bindSweeps`）。

横から見た絵なので「相手のまわりを一周する」は成立しない（地面の下を通れない）。
そこで「犬が相手より向こう側にいる状態で、リードが相手の上下を横切った回数」で数えている。
飛び越えて、戻って、また飛び越える。犬の素早さがそのまま武器になる。

なお**リードが届く範囲の相手しか締められない**。相手が飼い主に近づいてくるのを
待ってから仕掛けることになる。brute が遅いのはそのため。

### 3. 飼い主の足を止める

飼い主の**後ろ**でリードを張って踏ん張ると、飼い主が減速する（`ownerBrakeFactor`）。
先の敵を片付けるあいだ、待っていてもらえる。

## 怪異と、飼い主

怪異は**飼い主しか狙っていない**。犬には見向きもしない。犬は何をされても減らない。
減るのは飼い主の体力だけ（3つ）。

| 怪異 | 動き | 倒し方 |
| --- | --- | --- |
| `walker` | 地面を歩いて近づく | かみつき |
| `flyer` | 上下に揺れながら飛んでくる | かみつき（跳んで） |
| `brute` | 遅いが硬い | リードで締め上げる |

飼い主は最後まで何も分かっていない。噛み殺しても「急にどうした」、
締め上げても「こら、ぐるぐる回るな」、殴られても「いてっ。なんだ今の」としか言わない。

体力が尽きると時間が巻き戻り、散歩の最初からやり直す。ゴールは家の門。

## 数値の置き場所

**調整したい値は `src/config.ts` の `CONFIG` に集めてある。**
走る速さ、ジャンプ、リードの長さ、締め上げに必要な回数、怪異の速さ、カメラの寄り。

ブラウザのコンソールから触れる（毎フレーム参照しているのでリロード不要）:

```js
CONFIG.leashLength = 400     // リードを伸ばす
CONFIG.dogRunSpeed = 700     // もっと速く
CONFIG.leashSwingBoost = 2   // 反動ジャンプを強く
CONFIG.bindSweeps = 2        // 締め上げを楽に
CONFIG.viewHeight = 300      // 画面を寄せる
```

`game` もグローバルに出してある（`game.dog`, `game.leash.state`, `game.stage.enemies`）。

## 構成

```
src/
  config.ts             調整可能な数値。処理の中に数字を埋めない
  main.ts               起動
  Game.ts               ループ・状態遷移・戦闘判定・カメラ
  core/geom.ts          矩形の当たり判定と、軸ごとに押し戻す移動
  core/Draw.ts          Canvas2D の薄いラッパー（ワールドは y 上向き）
  core/Input.ts         キーボードとタッチを同じ口にまとめる
  core/Touch.ts         画面上のスティックとボタン
  entities/Dog.ts       柴犬。走る・跳ぶ・ダッシュ・かみつき
  entities/Owner.ts     飼い主。歩くだけ。動く支点であり、守る対象
  entities/Enemy.ts     怪異3種
  systems/Leash.ts      リード。制約・振り子・締め上げ・描画
  world/Stage.ts        ステージ（地形・湧き・背景）
  ui/UI.ts              DOM側の表示（canvas には文字を描かない）
```

物理は自前。矩形を軸ごとに動かして押し戻すだけ。1/120秒刻みで回している
（犬が速いのですり抜けるため）。ライブラリは Vite と TypeScript だけ。

## 検証の状態

- `npm run build`（`tsc --noEmit` + `vite build`）は通る
- ヘッドレス Chromium の自動操作で、以下は確認済み:
  走る／ジャンプの高さがキーの長さで変わる（長押し94px・タップ36px）／
  かみつきで walker が倒れる／brute にはかみつきが弾かれる／
  リードが張って振り子になる／そこでジャンプすると上向きに飛び出す／
  横切り4回で brute が締め上げられて沈む／ゴールに着くとクリアになる
- **手触り（面白いかどうか）は未確認。** そこは人が実際に触って判断するもの
- 実機の iPad では未確認。音は入れていない

もとは「時間を巻き戻して飼い主を事故から救う」3Dの散歩ゲームだった。
そちらは消さずに残してある。

- 遊ぶ: `/walk3d.html`（公開先だと `.../shiba-loop/walk3d.html`）

## 公開

`main` に push すると GitHub Actions が Vite でビルドして GitHub Pages へ出す
（`.github/workflows/pages.yml`）。2Dアクションが `index.html`、3D版が `walk3d.html`。

## やらないこと

美麗な絵、シェーダー、物理エンジン、セーブ、設定画面、ステージ選択、音声、
完璧なコード設計。プロトタイプなので、そこには時間を使っていない。
